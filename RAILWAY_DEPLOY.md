# Инструкция по развертыванию Discord-бота на Railway через GitHub

Эта инструкция поможет тебе выгрузить бота в GitHub и запустить его на хостинге **Railway** в режиме 24/7.

---

## Шаг 1. Подготовка GitHub-репозитория

1. Создай новый репозиторий на [GitHub](https://github.com/new) (например, `targetmusicbot`).
   - Сделай его **Private** (приватным) или **Public** (публичным). Не добавляй README/лицензию, если создаешь пустой репозиторий.
2. В терминале в папке проекта выполни следующие команды:

```bash
# Инициализация git (если еще не сделано)
git init

# Добавление всех файлов (файл .env автоматически игнорируется)
git add .

# Создание первого коммита
git commit -m "feat: jockie music bot with railway docker setup"

# Указание ветки main
git branch -M main

# Привязка к твоему GitHub-репозиторию (замени ссылку на свою!)
git remote add origin https://github.com/ТВОЙ_ЮЗЕРНЕЙМ/targetmusicbot.git

# Отправка кода в GitHub
git push -u origin main
```

---

## Шаг 2. Настройка бота в Discord Developer Portal

1. Перейди на [Discord Developer Portal](https://discord.com/developers/applications).
2. Выбери своего бота и перейди во вкладку **Bot**.
3. В разделе **Privileged Gateway Intents** ОБЯЗАТЕЛЬНО включи:
   - ✅ **MESSAGE CONTENT INTENT**
   - ✅ **SERVER MEMBERS INTENT**
4. Скопируй токен бота кнопкой **Reset Token** -> **Copy**.

---

## Шаг 3. Создание проекта на Railway

1. Зарегистрируйся или авторизуйся на [Railway](https://railway.com/) через GitHub.
2. Нажми кнопку **New Project** (или **+ Create**).
3. Выбери **Deploy from GitHub repo**.
4. Найди и выбери свой репозиторий `targetmusicbot`.
5. Railway автоматически обнаружит `Dockerfile` и начнет сборку контейнера.

---

## Шаг 4. Настройка переменных окружения (Variables)

1. В проекте на Railway нажми на созданный сервис.
2. Перейди во вкладку **Variables**.
3. Нажми **New Variable** (или **RAW Editor**) и добавь обязательные переменные:

| Переменная | Значение | Описание |
|---|---|---|
| `DISCORD_TOKEN` | `твой_токен_бота` | Токен из Discord Developer Portal |
| `PREFIX` | `t!` | Префикс команд |

*Опциональные переменные (для поддержки Spotify ссылок):*
| Переменная | Значение | Описание |
|---|---|---|
| `SPOTIFY_CLIENT_ID` | `...` | Client ID из Spotify Dashboard |
| `SPOTIFY_CLIENT_SECRET` | `...` | Client Secret из Spotify Dashboard |

4. После добавления переменных Railway автоматически перезапустит бота.

---

## Шаг 5. Проверка работы

1. Перейди во вкладку **View Logs** в Railway.
2. Ты должен увидеть:
   - `ffmpeg найден: ...`
   - `yt-dlp найден (PATH), версия ...`
   - `Бот вошёл как ТвоёИмя#0000`
3. В Discord напиши команду `t!help` или `t!play <название песни>`.

---

## Список команд бота (`t!x`):
- `t!play <запрос/ссылка>` — включить трек или плейлист (YouTube, Spotify, SoundCloud).
- `t!search <запрос>` — поиск трека на YouTube с интерактивным выбором (кнопками 1-5 или цифрой в чат).
- `t!skip` — пропуск трека (автор скипает сразу, остальные запускают голосование $\ge 50\%$).
- `t!next` — переход к следующему треку (логика skip).
- `t!pause` — пауза (через 5 минут неактивности бот выйдет из канала).
- `t!resume` — снять с паузы.
- `t!repeat [current|queue|disable]` — режим повтора (трек, очередь или выключить).
- `t!queue` — список очереди треков с пагинацией.
- `t!clear` — очистить очередь ожидания.
- `t!autoplay` — переключить автовоспроизведение похожих треков после окончания очереди.
- `t!lyrics [песня]` — текст текущей или заданной песни.
- `t!help [команда]` — список команд или подробная справка по конкретной команде.
- `t!leave` — отключить бота от голосового канала.
